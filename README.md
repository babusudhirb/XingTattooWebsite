# XING TATTOO STUDIO

A modern, responsive website for **XING Tattoo Studio** in Brookefield, Bengaluru.

## Features

- Hero section with a mirrored, background-blended statue tattoo image
- Studio stats and specialized tattoo style cards
- "The Artist" section with the founder portrait and 15+ years badge
- Filterable tattoo gallery with hover overlays
- Client testimonial marquee slider
- Exclusive Ink Offer popup with countdown and focus trap
- Floating social dock (Instagram, WhatsApp, Call) with scroll-triggered transition
- FAQ section and smooth-scroll navigation

## Local Development

You need Node.js and a package manager (npm or Bun):

```sh
git clone https://github.com/altafs45/XING-TATTOO-STUDIO.git
cd XING-TATTOO-STUDIO
npm install   # or bun install
npm run dev   # or bun run dev
```

The dev server starts at `http://localhost:8080`.
