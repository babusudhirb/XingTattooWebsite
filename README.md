# Xing Premium Tattoo Studio — Website

Website of **Xing Premium Tattoo Studio**, Brookefield, Bengaluru — https://www.xingtattoo.in.
Built with TanStack Start, React, TypeScript and Tailwind CSS. Every page is prerendered to a static
`.html` file at build time, so any static host can serve it and crawlers get the full HTML.

## Commands

```sh
npm install        # once (Node 22.18+; .nvmrc pins 24)
npm run dev        # local site with live reload at http://localhost:3000
npm run build      # production build → .output/public/  (the folder a host serves)
npm run preview    # serve .output/public like the live host at http://localhost:4173
npm run qa         # with the preview running: build + SEO, NAP, link and mobile checks
```

Other checks (preview running): `npm run lighthouse`, `node scripts/qa/text-budget.mjs`
(mobile text budget), `node scripts/qa/url-snapshot.mjs out.json` (URL parity snapshots).

## Blog

Posts live in `content/blog/<slug>.md`. `scripts/blog-plugin.ts` turns them into pages at build
time and checks every internal link.

- **Scheduling:** posts with `draft: true` and a `publishAt` date go live on the first build on or
  after that date (India time). `.github/workflows/scheduled-rebuild.yml` triggers a deploy on
  Mondays and Thursdays. Preview the schedule with `BLOG_BUILD_DATE=2027-12-31 npm run build`.
- **Images:** `python scripts/blog-images.py <slug>` makes the hero, card, OG and body images.
- **Checks:** `python scripts/qa/check-blog.py` validates titles, descriptions, keywords, links,
  FAQs, word counts and bans price figures.

## Hosting

See [docs/DEPLOY.md](docs/DEPLOY.md): Cloudflare Pages connected to this GitHub repo (deploys on
every push to `main`), or Hostinger by uploading `.output/public/`.

The booking and offer forms email the studio through a server function
(`src/lib/booking-request.ts`). Static hosting can't run it, so there the forms hand the request
to WhatsApp — every booking still reaches the studio.
